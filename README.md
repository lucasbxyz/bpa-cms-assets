# BPA CMS Assets

Bildbestand für das BPA Webflow CMS (Bauprodukte für Abdichtung).

## Struktur

```
images/
├── CEMflex/                # Fugenbleche, Sollrisselemente, Befestigungen
├── CEMstar/                # Dichtungsschlämmen
├── CEMswell/               # Quellgummi
├── CEMtec/                 # Fugendichtbänder
├── CEMtobent/              # Bentonitmatten, Spachtelmasse
├── Dualproof/              # Frischbetonverbundsysteme + Tapes
├── Injektionsschlauch/     # Injektions-/Verpressschläuche & Zubehör
├── Kleb und Dichtstoffe/   # CEM 805/807/811, CEMsil
├── Quellmax/               # Bentonitquellbänder
├── Quellvlies/             # EasySeal, SilverSeal
└── Sonstiges/              # Sonstige Assets
```

Alle Bilder sind transparente PNGs für die Verwendung im Webflow CMS.

## Verwendung

Die Raw-URLs haben das Format:

```
https://raw.githubusercontent.com/lucasbxyz/bpa-cms-assets/main/images/<Ordner>/<Datei>.png
```

Sonderzeichen (Leerzeichen, Umlaute, `&`) müssen in URLs encodiert werden.
